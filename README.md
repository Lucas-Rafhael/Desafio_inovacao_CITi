# PTA | CITi

Plataforma desenvolvida para centralizar a agenda do Programa de Treinamento e Ambientação (PTA) do CITi.

## Sobre o projeto

O objetivo é facilitar o acesso à programação do PTA, reunindo em um só lugar as atividades, datas, horários, materiais e gravações dos encontros.

## Tecnologias

- HTML
- CSS
- JavaScript
- Google Sheets
- GitHub Pages

## Como funciona

As atividades são cadastradas em uma planilha do Google Sheets, que funciona como fonte de dados da aplicação.

O JavaScript busca essas informações e as exibe automaticamente na página, organizadas por data.

Assim, é possível atualizar a agenda diretamente pela planilha, sem precisar alterar o código.

## Executar localmente

1. Clone o repositório.
2. Abra a pasta no VS Code.
3. Execute o `index.html` com o Live Server.

## Publicação

O projeto utiliza o GitHub Pages para hospedagem.

Desenvolvido como parte do desafio de Inovação do Processo Seletivo do CITi.
